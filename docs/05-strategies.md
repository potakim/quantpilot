# 05 · 전략 명세

전략은 `Strategy.on_bar(ctx) -> list[Target]`로만 표현된다. 여기 적힌 규칙이 코드(`quantpilot/strategies/`)와 다르면 코드가 틀린 것이고, 바꾸려면 이 문서와 ADR을 먼저 고친다.

## 공통

| 항목 | 규칙 |
| --- | --- |
| 비중의 기준 | 전략 배정 자본(총 자본 × allocation). `Target.weight=1.0`은 배정 자본 전부 |
| 배정 상한 | 장기(GEM+GTAA) ≤ 80%, 단타(변동성 돌파+ORB) 합산 ≤ 20% (RiskRules), 현금 ≥ 10% 권장 |
| 룩어헤드 | `Target.price`를 주는 전략은 현재 봉의 close 사용 금지. 월간 전략은 월말 봉 close를 쓰되 체결도 그 봉 close(종가 단일가)에 |
| 비용 | 백테스트·페이퍼 모두 `CostModel` 프리셋: 업비트 수수료 0.05%·슬리피지 0.05% / KRX 수수료 0.015%·슬리피지 0.05%·매도세 0.20% / 미국 수수료 0.10%·슬리피지 0.01%(QQQ ≈ 5¢/주, 논문 손익분기 2.2¢보다 보수적). 변경 시 ADR |
| 청산 우선 | 같은 봉에서 exit와 entry가 나오면 exit 먼저 |
| 파라미터 | `ParamSpec` 범위 밖 값은 API가 거부. 범위는 공개 백테스트의 강건 구간 |

## 1. 변동성 돌파 + 이평 스코어 + 목표 변동성 (`vol_breakout`)

| 항목 | 값 |
| --- | --- |
| 시장 · 봉 | 업비트 KRW, 일봉(09:00 기준) + 1분봉(돌파 감시) |
| 대상 | BTC, ETH, SOL, XRP, ADA (설정 가능, 최대 10개) |
| 목표가 | `open_t + (high_{t-1} − low_{t-1}) × K` |
| 진입 | 1분봉 체결가가 목표가 이상 → 시장가 매수, 하루 1회. `Target(price=목표가)` |
| 비중 | `min(max_weight, vol_w × ma_score) / n_symbols`, `vol_w = min(1, target_vol / 전일 변동폭%)`, `ma_score = 종가 > MA(3,5,10,20) 개수 / 4` (전일 종가 기준) |
| 청산 | 전략이 매 봉 `Target(weight=0, price=open)`을 먼저 낸다(= 다음 날 09:00 시가). 실시간에서는 `scheduler.upbit_daily_exit`가 09:00 봉을 트리거한다. 손절: 진입가 × (1 − 2 × 전일 변동폭%) — `Target.stop`, 1단계 `on_stop_check`가 감시. **0단계 백테스터는 stop과 RiskManager를 적용하지 않는다**(P1-04에서 TickRunner로 통합) |
| 파라미터 | `k` 0.3~0.8 (기본 0.5), `target_vol` 0.2%~3% (기본 1%), `ma_windows`, `noise_k` bool, `max_weight` |
| 판단 계층 | 진입 전 판단 모델 게이팅 적용. LLM 합의는 **미적용**(1분 단위 반응 필요) — 대신 08:10에 하루 1회 LLM 2모델이 대상 코인별 news_risk를 사전 심사해 위험 코인은 당일 제외 |
| 공개 수치 | 강환국, BTC 2013.10~2018.3, 비용 0.1%: 0.5% 타겟 + 5일선 필터 연 17.4%·MDD 6.5% / 1% 타겟 무필터 연 30.5%·MDD 27.3% |
| 알려진 약점 | 횡보장 잦은 손절, 슬리피지에 민감(하루 5회 시장가 왕복). 2022년 이후 공개 재현은 열위 |

## 2. 듀얼 모멘텀 GEM (`gem`)

| 항목 | 값 |
| --- | --- |
| 시장 · 봉 | 미국 ETF(KIS 해외 실전 / Alpaca 페이퍼), 월간(일봉 기반) |
| 자산 | SPY, ACWX(해외주식), AGG(채권), BIL(현금 대용) |
| 룩백 | 6·9·12개월 앙상블, 각 1/3 |
| 규칙 | 룩백마다: `r(SPY) > r(BIL)`이면 주식(SPY vs ACWX 중 높은 쪽), 아니면 AGG |
| 리밸런싱 | 월 마지막 거래일 미국장 마감 5분 전 시장가 (KST 익일 04:55). 목표·현재 비중 차이가 자본의 0.2% 미만이면 주문 생략(`min_trade_frac`) |
| 판단 계층 | 판단 모델 + LLM 합의 적용. 단, LLM이 hold를 내면 **현금(BIL)이 아니라 현 포지션 유지** — 장기 전략에서 AI가 매달 개입하면 성과가 망가지므로 합의 실패 시 "변경 안 함"이 기본 |
| 공개 수치 | Petit 2026, 1971.1~2026.7: CAGR 15.18%, Sharpe 0.83, MDD −21.7% (S&P 11.27%, −50.9%). 2010 이후 연 −4.8%p |
| 알려진 약점 | 2010년 이후 열위, 2021~23 방어자산 보유 중 최대 낙폭. 세금(양도세 22%)은 백테스트 미반영 |

KRX 버전(`gem_krx`, 2단계): TIGER 미국S&P500 / KODEX 선진국MSCI / KODEX 미국채10년 / KODEX 단기채권. 15:20 종가 단일가.

## 3. 10개월선 자산배분 GTAA (`gtaa`)

| 항목 | 값 |
| --- | --- |
| 시장 · 봉 | KRX ETF(KIS), 월간 |
| 자산 (각 20%) | 360750 TIGER 미국S&P500, 251350 KODEX 선진국MSCI, 308620 KODEX 미국채10년선물, 130680 TIGER 원자재, 329200 TIGER 리츠 |
| 규칙 | 월말 종가 > 10개월(210거래일) SMA → 보유, 아니면 현금(또는 `cash_symbol`) |
| 리밸런싱 | 월 마지막 거래일 15:20 종가 단일가 |
| 판단 계층 | GEM과 동일(합의 실패 = 변경 안 함) |
| 공개 수치 | Faber 1973~2012: MDD 46% → 10% 미만, 수익률은 매수보유와 유사 |
| 대안 | 영구 포트폴리오(주식·장기채·금·현금 25%) 토글 — 2단계 |

## 4. 5분 ORB (`orb`)

| 항목 | 값 |
| --- | --- |
| 시장 · 봉 | 미국(QQQ), 5분봉. **페이퍼 전용**(Alpaca). 실전 전환은 G2 통과 후 별도 승인 |
| 진입 | 첫 5분봉(09:30~35 ET) 종가 > 시가면 둘째 봉 시가 롱. 숏은 `allow_short=False` 기본(국내 증권사 불가). 켜면 백테스터·브로커도 `allow_short=True`여야 하며, 숏 청산(BUY)의 리스크 예외 처리는 1단계 과제 |
| 손절 · 목표 | 첫 봉 저가 / 10R. 15:55 ET 강제 청산 |
| 수량 | 거래당 리스크 `risk_per_trade`(기본 1%) / R. 실시간에서는 RiskManager가 다시 1% 룰·단타 상한 적용(0단계 백테스터는 미적용) |
| 판단 계층 | 판단 모델 + LLM 합의(둘째 봉까지 5분 여유) |
| 공개 수치 | Zarattini & Aziz 2023, QQQ 2016~2023: 연 31%, Sharpe 1.12, 승률 24%. Brusco 재현: 손익분기 슬리피지 ≈ 2.2¢/주, 2¢ 적용 시 CAGR 2.7% |
| 관문 | G2에서 슬리피지 2¢ 포함 Sharpe > 0.5 못 넘으면 실전 후보에서 제외 |

## 5. 시장 캘린더와 시간표 (KST)

| 시각 | 시장 | 동작 |
| --- | --- | --- |
| 08:00 | — | KIS 토큰 갱신 |
| 08:10 | 업비트 | 대상 코인 news_risk 사전 심사(LLM 2모델), 위험 코인 당일 제외 |
| 08:30 | — | 아침 브리핑(Claude): 오늘 일정·보유·리스크 |
| 09:00 | 업비트 | 전일분 청산 → 목표가 재계산 → 돌파 감시 시작 |
| 09:00~15:30 | KRX | 정규장. GTAA·GEM-KRX(2단계)는 15:20에만 주문 |
| 15:20 | KRX | 종가 단일가 주문 |
| 16:00~20:00 | KRX 애프터마켓 | 청산 전용(지정가). 신규 진입 없음 |
| 20:30 | — | 사후 리뷰(Claude) |
| 22:30 (23:30) | 미국 | 개장. ORB 첫 봉 |
| 22:35 (23:35) | 미국 | ORB 진입 |
| 04:55 (05:55) | 미국 | ORB 청산, 월말이면 GEM 리밸런싱 |

휴장일·조기 폐장은 `MarketClock`(내장 표, ADR 0009). 미국 조기 폐장(13:00 ET)일은 ORB 청산 12:55 ET. 업비트는 연중무휴이나 거래소 점검 공지(보통 새벽)를 `events.py`에 수동 등록.

## 6. 전략 추가 절차

1. `docs/05-strategies.md`에 위 표 형식으로 명세 + 공개 수치·출처 추가.
2. `strategies/<name>.py`에 `Strategy` 구현, docstring에 출처.
3. `strategies/__init__.py` REGISTRY 등록 → `tests/test_backtest.py` 파라미터화 테스트가 자동 포함.
4. `scripts/verify_g1.py`의 `PUBLIC`에 공개 수치 등록.
5. 룩어헤드 테스트(`test_<name>_no_lookahead`) 작성.
