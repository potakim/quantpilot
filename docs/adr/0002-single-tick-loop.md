# 0002 · 백테스트·페이퍼·실전이 같은 틱 루프를 쓴다

상태: 승인 (2026-09-29)

## 맥락
백테스트 엔진과 실전 엔진이 따로 있으면 두 코드의 미묘한 차이(체결 시점, 비중 계산, 청산 순서)가 성과 차이로 나타나고 원인을 찾기 어렵다. 0단계 `Backtester.run`은 자체 루프를 갖고 있다.

## 결정
1단계에서 `engine/tick.py::TickRunner`를 만들고, 백테스터는 `TickRunner + PaperBroker + StubJudge + 가짜 clock`으로 재구성한다. 차이는 주입되는 브로커·판단 모델·시계뿐이다. 불변식 테스트 #2로 같은 데이터에서 같은 체결이 나오는지 검증한다.

## 결과
- 전략·리스크 코드에 "백테스트 모드" 분기가 없어진다.
- 백테스트 속도는 vectorbt보다 느리다 → 파라미터 탐색은 vectorbt, 최종 검증은 TickRunner로 역할 분리.
