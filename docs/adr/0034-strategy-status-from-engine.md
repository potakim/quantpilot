# 0034 · `strategy.status`는 실시간 엔진이 보낸다

상태: 승인 (2026-10-05)

## 맥락
2026-10-05 점검(t39)에서 확인했다. 화면이 구독하는 WS 채널 `strategy.status`(03 §3)를 받는 화면은 있는데, 실제로 화면까지 오는 메시지가 하나도 없다.

1. **scheduler**:
   - `upbit_daily_exit`(09:00)가 `publish_breakout_status`로 `strategy.status`를 발행한다(04 §8 표).
   - scheduler의 `JobContext`는 `bus`를 넘기지 않아 기본값 `LogBus`를 쓴다. scheduler 프로세스에는 실시간 허브(Redis) 연결이 없다. 그래서 이 메시지는 로그에만 남는다.
   - 모양도 03 문서와 다르다(`{strategy, market, ts, k, targets}` — 화면이 키로 쓰는 `name`이 없다).
2. **엔진**: `HubBus`에 `strategy.status` 경로가 없다. 엔진은 이 채널을 보내지 않는다.
3. **화면**:
   - `name`이 없는 메시지는 버린다(`web/lib/ws.ts`).
   - 전략 목록(`useStrategies`)은 주기 갱신이 없고, `strategy.status`를 받을 때만 다시 읽는다. 그래서 대시보드 활성 전략 표(포지션·이번 달·MDD·켜기/끄기)는 페이지를 연 순간 그대로 머문다(창을 다시 볼 때만 갱신).
   - 활성 전략 표의 토글은 WS의 `enabled`를 저장값보다 우선한다(`live[s.name]?.enabled ?? s.enabled`). 엔진이 이 값을 보내기 시작하면, 사용자가 토글을 바꾼 직후 엔진이 설정을 다시 읽기 전(최대 5초)까지 토글이 옛 값으로 되돌아 보인다.

## 결정
1. **보내는 쪽 = 실시간 엔진** (`MarketEngine`):
   - 엔진은 하트비트(`on_link`, 5초)마다 전략 설정을 다시 읽은 뒤(`_sync_configs`, ADR 0032) 전략별 상태를 만든다.
   - 지난번에 보낸 것과 달라진 전략만 허브 채널 `strategy.status`로 보낸다. 엔진이 시작하면(`restore`) 한 번 모두 보낸다.
   - 허브가 없거나 발행이 실패해도 매매는 계속한다(표시용).
2. **모양** — 전략 하나에 메시지 하나, `{name, market, enabled, allocation, position:{심볼: 수량}}`:
   - `enabled`·`allocation`은 엔진이 지금 적용 중인 값이다(저장값이 아니다).
   - `position`은 ON 원장의 그 전략 보유 수량이다(게이팅 OFF 섀도 원장은 뺀다).
   - `next_action`은 싣지 않는다. 변동성 돌파 목표가 같은 오늘 할 일은 REST `/schedule`이 봉으로 계산하고, 화면은 1분마다 다시 읽는다.
3. **scheduler 09:00 발행**:
   - 그대로 둔다. 로그에 남는 목표가 기록으로 쓰인다.
   - 04 §8 표에 "로그로만 남고 화면은 `/schedule`에서 읽는다"고 적는다. scheduler에 허브 연결을 붙이는 일은 하지 않는다(화면에 필요한 값이 이미 REST에 있다).
4. **화면**:
   - `strategy.status`를 받으면 이전 값에 합친다(일부 필드만 와도 나머지는 남는다). 그리고 전략 목록을 다시 읽는다(이미 있는 연결).
   - 활성 전략 표의 토글은 저장값(REST `enabled`)만 쓴다. 사용자가 바꾼 값이 곧 화면 값이고, 엔진은 5초 안에 따라온다.
   - 전략 목록은 메시지가 없어도 1분마다 다시 읽는다. 이번 달 손익·MDD는 체결이 없어도 시세로 바뀌기 때문이다.

## 결과
- 엔진이 체결하거나 설정을 반영하면 5초 안에 대시보드 활성 전략 표가 새로 고쳐진다. 페이지를 다시 열 필요가 없다.
- 토글은 누른 값 그대로 보인다(엔진이 따라오기 전의 되돌림 없음).
- 데모 API는 엔진 대신 같은 모양의 메시지를 보낸다. 데모에서 토글을 바꾸면 메시지가 오는 것을 확인할 수 있다.
- 2단계에서 다른 시장의 엔진을 붙이면 같은 코드로 그 시장 전략의 상태도 나간다.
