# 0031 · 실시간 엔진이 도는 시장(LIVE_MARKETS)만 계좌·일정·주문에 포함하고, 나머지 시장은 화면에서 "2단계 예정"으로 보인다

상태: 승인 (2026-10-04)

## 맥락
2026-10-04 화면·시장별 점검에서, 1단계(업비트만 실시간)인데도 API와 화면이 한국주식·미국주식을 이미 도는 시장처럼 다루는 것을 확인했다.

1. **유령 계좌**: `GET /portfolio`가 모든 시장을 돌며 `restore_account`를 부른다. 저장된 계좌가 없으면 초기 현금(₩10,000,000·$10,000)이 그대로 나온다. 그래서 대시보드 총 자산·현금이 부풀고(업비트 ₩1천만 → 총 ₩2천만), 오늘 손익 %는 반쯤 줄어들고, "미국 제외 (환율 없음)" 문구가 늘 붙는다.
2. **유령 일정**: `GET /schedule`이 돌지 않는 잡(KRX 종가 주문, KIS 토큰, 미국 ORB, GEM 리밸런싱, 연결되지 않은 아침 브리핑)을 "완료"로 싣는다. 화면에는 잡 ID(`krx_close_orders`)가 그대로 보인다.
3. **갈 곳 없는 주문**: `POST /orders`가 KRX·미국 주문을 받아 `q:orders:krx/us`에 넣는다. 이 큐를 읽는 엔진은 없어서 주문이 영원히 "대기"로 남는다.
4. **조용히 틀리는 백테스트**: yfinance·FDR 로더는 봉 간격을 무시하고 일봉을 돌려준다. ORB(5분봉)를 실데이터로 돌리면 일봉으로 계산돼 매매가 0건이고, 오류도 나지 않는다.
5. **화면**:
   - 거래 화면의 관심 종목이 세 시장 15종목을 섞어 보여 주고, 상단 시장 탭으로 걸러지지 않는다. KRX·미국 행은 30초마다 실패하는 시세를 요청한다.
   - KRX·미국 종목 화면은 유령 현금을 보여 주고 주문 버튼이 눌린다.
   - 차트 가격축이 `151000000.00`처럼 원시 숫자로 보인다.
   - 일봉 실시간 갱신이 UTC 자정에 봉을 끊는다. API 일봉의 시작 시각과 다를 수 있다.

## 결정
1. **`LIVE_MARKETS`** (`core/models.py`): 실시간 엔진이 도는 시장 집합이다. 1단계 값은 `{upbit}`이다. 배포 가드(`ops/deploy_guard.LIVE`)도 이 값을 쓴다. 2단계에서 시장 엔진을 붙일 때 이 한 곳만 바꾼다.
2. **`/health`**: `live_markets`를 함께 돌려준다. 화면은 이 값으로 시장별 표시를 정한다.
3. **`/portfolio`**:
   - 시장마다 `active`를 둔다. 조건은 `LIVE_MARKETS`에 있거나, 저장된 계좌 흔적(포지션 또는 저장된 페이퍼 현금)이 있는 것이다.
   - 총 자산·오늘 손익·환율 경고는 `active` 시장만 센다. 비활성 시장도 `by_market`에는 남긴다(값은 0으로 보지 않고 `active:false`로 표시).
4. **`/schedule`**: 시장 잡은 `LIVE_MARKETS` 시장 것만 싣는다. scheduler에 연결되지 않은 `morning_brief`는 뺀다. 각 항목에 한국어 `title`을 준다. 화면은 잡 ID 대신 이 값을 쓴다.
5. **`POST /orders`**: `LIVE_MARKETS`에 없는 시장은 409 `MARKET_NOT_LIVE`로 거부한다. 큐에 넣지 않는다.
6. **백테스트 데이터**:
   - yfinance·FDR 로더는 `1d`가 아니면 `ValueError`를 던진다.
   - `POST /backtests`는 일봉 전용 소스에 분봉 전략(ORB 5분봉)을 요청하면 400 `INVALID_PARAM`을 돌려준다.
   - 합성 데이터는 그대로 허용한다.
7. **화면**:
   - 관심 종목은 상단 시장 탭으로 거른다. 비활성 시장 행은 시세를 요청하지 않고 "2단계 예정"으로 표시한다.
   - 비활성 시장 종목 화면은 안내 배너를 보여 주고, 유령 현금을 숨기고, 주문 패널을 잠근다.
   - 차트 가격축은 크기에 맞춘 자릿수(1,000 이상은 정수 + 천 단위 쉼표)로 표시한다.
   - 실시간 봉 갱신은 마지막 봉의 시작 시각을 기준으로 봉 간격을 이어 붙인다. API 봉의 시작 시각과 늘 맞는다.

## 결과
- 대시보드 총 자산·현금·오늘 손익 %가 실제로 운영하는 계좌만 반영한다. 데모처럼 KRX·미국 포지션이 저장돼 있으면 그대로 센다.
- 일정·주문·관심 종목이 1단계 범위와 맞는다. 사용자가 돌지 않는 시장에 주문하거나 그 시장의 시세를 기다리는 일이 없다.
- 2단계에서 시장 엔진을 붙이면 `LIVE_MARKETS`에 추가하는 것만으로 계좌·일정·주문·화면이 함께 열린다.
