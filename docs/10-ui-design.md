# 10 · 화면 디자인 핸드오프

원본은 Claude Design 캔버스 "QuantPilot 화면 디자인"(6개 아트보드). 각 아트보드의 HTML 원본이 `docs/design/*.dc.html`에 있다 — **구현 시 이 파일을 열어 레이아웃·간격·색·문구를 그대로 따른다.** `canvas.json`은 아트보드 배치 정보다.

`.dc.html`은 Claude Design 전용 포맷(`<x-dc>` 루트, `{{accent}}` 홀 하나)이지만 본문은 인라인 스타일의 순수 HTML이라 브라우저에서 바로 열린다. `{{accent}}`는 `#8B7CF6`으로 읽는다.

## 2. 디자인 토큰

`web/app/globals.css`의 CSS 변수로 정의한다. 값은 아트보드에서 추출.

```css
:root {
  /* 배경 */
  --bg-0: #0B0F14;   /* 페이지 */
  --bg-1: #0F141B;   /* 헤더·사이드바 */
  --bg-2: #121820;   /* 카드 */
  --bg-3: #1A222C;   /* 카드 안 강조 블록, 선택된 탭 */
  --bg-4: #2A3442;   /* 비활성 토글, 거래량 바 */
  --line:  #253040;  /* 테두리 */
  --line-2: #1E2734; /* 표 행 구분, 차트 그리드 */

  /* 텍스트 */
  --ink:   #E8EDF3;
  --ink-2: #C5CDD8;
  --muted: #8A96A6;
  --muted-2: #5C6878;

  /* 의미색 (국내 관행: 상승 빨강 · 하락 파랑) */
  --up:    #F4516C;  --up-bg: #3A1B26;
  --down:  #4F8CFF;  --down-bg: #1B2A44;
  --ok:    #2ECC8A;  --ok-ink: #6EE7B7;  --ok-bg: #123626;    /* 연결됨, 승인, ON 토글 */
  --warn:  #F5A524;  --warn-ink: #F5C57A; --warn-bg: #2A2110; --warn-line: #7A5A14;  /* 페이퍼 모드, 보류, 관문 미달 */
  --ai:    #8B7CF6;  --ai-ink: #C4B8FF;  --ai-bg: #241F45;  --ai-line: #2E2A4D;    /* AI 판단 요소 전부 */

  /* 서체 */
  --font-sans: 'IBM Plex Sans KR', system-ui, sans-serif;
  --font-mono: 'IBM Plex Mono', monospace;   /* 모든 숫자·시각·코드 */

  /* 반경 */
  --r-card: 14px; --r-block: 10px; --r-btn: 8px; --r-pill: 999px;
}
```

규칙:

- **숫자는 전부 모노스페이스 + `font-variant-numeric: tabular-nums`**. 가격·손익·확신도·시각 모두.
- 보라(`--ai`)는 AI 판단 관련 요소와 화면 원본이 강조색(`{{accent}}`)으로 칠한 자리에만 쓴다: 확신도 바, 판단 카드 테두리, "AI 권장" 버튼, 링크·초점 테두리, 그리고 원본의 입력 강조(슬라이더 손잡이, 선택한 값 칩, 선택한 라디오, "설정 저장" 버튼, 자본 배분 바의 단타 조각). 원본에 없는 곳에 새로 보라를 쓰지 않는다 (2026-10-04 결정: 새 화면은 원본을 따른다).
- 주황(`--warn`)은 "사람이 확인해야 할 상태": 페이퍼 모드 배지, 보류, 관문 미달, 월 손실 게이지(60% 이상일 때), 과최적화 경고.
- 초록(`--ok`)은 시스템 상태(연결됨, ON, 승인)에만. 수익에는 쓰지 않는다(수익은 빨강).
- 카드는 `--bg-2` + `1px solid --line` + `--r-card`, 패딩 18~20px. 카드 안의 강조 블록은 `--bg-3` + `--r-block`, 패딩 10~12px.
- 그라디언트·그림자·이모지 없음. 아이콘은 인라인 stroke SVG(1.8px, round cap), 18px(내비) / 14~16px(인라인).

## 3. 공통 레이아웃 (데스크톱)

```
┌ header 56px ───────────────────────────────────────────────────────────────┐
│ 로고 QuantPilot │ 시장 탭(전체·코인·국내·미국) │ [● 페이퍼 모드] │   시각 · 연결 상태 · 알림 · 아바타 │
├ nav 220px ┬ main (padding 24px, gap 16~20px) ────────────────────────────────┤
│ 대시보드   │                                                                 │
│ 거래·차트  │                                                                 │
│ 전략 설정  │                                                                 │
│ AI 판단   │                                                                 │
│ 백테스트   │                                                                 │
│ 포트폴리오 │                                                                 │
│ …         │                                                                 │
│ [월 손실   │                                                                 │
│  한도 카드]│                                                                 │
│ 설정·API키 │                                                                 │
└───────────┴─────────────────────────────────────────────────────────────────┘
```

- 헤더의 **모드 배지**(페이퍼/실전)와 **연결 상태**는 모든 화면에 항상 보인다. 실전 모드는 배지가 빨강 계열(`--up-bg`/`--up`)로 바뀐다.
- 사이드바 하단 **월 손실 한도 카드**는 모든 화면에 고정. 게이지는 `−1.2% / 한도 −5%` 형식, 색은 사용률(|월 손익| ÷ |한도|) 24% 이하 초록 → 60%까지 주황 → 그 이상 빨강(ADR 0018). 월 손익이 플러스면 사용률 0%.
- 활성 내비 항목: `--bg-3` 배경 + `--ink`, 나머지 `--muted`.

## 4. 화면별 구성과 상태

### 4.1 대시보드 (`Main.dc.html`)

행 1: KPI 카드 4개(총 자산 / 오늘 손익 / 실행 중 전략 n/4 / AI 판단 오늘 n회·비용). AI 카드만 `--ai-line` 테두리.
행 2: 자산 곡선 30일(전략 합산 실선 `--ai`, 벤치마크 점선 `--muted-2`, 30/90/1년 탭) + 오늘 일정 타임라인(시각 모노, 완료 ● 초록 / 다음 ● 보라 / 예정 ○).
행 3: 활성 전략 표(전략·시장·ON/OFF 토글·포지션·이번 달·MDD, 페이퍼 전용 전략은 "페이퍼만" 주황 배지) + 최근 AI 판단 3건(시각·결과·확신도 바·LLM 배지).

상태: 데이터 로딩은 카드 골격(skeleton), 엔진 다운은 헤더 연결 상태 빨강 + 상단 배너, 할트 중은 활성 전략 표 위에 주황 배너 "신규 진입 중단: {사유}".

### 4.2 거래 · 차트 (`Trade.dc.html`)

3열: 관심 종목+호가(230px) / 차트+체결 탭(가변) / AI 판단+주문 패널(310px).

- 관심 종목 행에 전략 상태 부제(목표가 대비 −1.9%, 돌파·보유 중, AI 보류·뉴스 리스크).
- 차트: TradingView Lightweight Charts. 캔들 빨강/파랑, 20일선 주황(`--warn`), **변동성 돌파 목표가 점선(`--ai`) + 라벨**, 진입 마커(초록 삼각), 현재가 라벨(`--up`). 1/5/15분·1시간·일 탭.
- 하단 탭: 오늘 체결 / 미체결 / 보유 포지션. 체결 행의 마지막 열은 AI 판단 요약("확신도 0.88 · 절반 사이징 · 2/2 승인").
- AI 판단 패널(`--ai-line` 테두리): 확신도 큰 숫자 + 게이팅 결과, 원자 질문 6개 바(regime은 최고 확률 라벨), LLM 2모델 카드(모델명·승인/보류·이유 한 줄), 리스크 게이트 체크 4개(✓ 초록).
- 주문 패널: 매수/매도 탭(매수 활성 = `--up-bg`), 시장가/지정가, 금액 입력(모노), 비중 버튼 10/25/**AI 권장 50%**(보라 테두리)/100, 예상 수량·수수료·손절가, 큰 버튼 "페이퍼 매수 · ₩2,620,000". 하단 문구 "수동 주문도 리스크 게이트를 통과해야 체결됩니다".

상태: 리스크 거부 시 주문 버튼 아래 주황 블록에 `RiskDecision.reason`; 지정가 대기 중은 미체결 탭 카운트 증가.

### 4.3 전략 설정 (`Strategy.dc.html`)

자본 배분 바(총 자본 = `/portfolio` 합계, 배분 있는 전략 장기 → 단타 순 → 현금, 배분 0은 범례에만 점선) → 전략 카드 2×2(GEM · 변동성 돌파 / GTAA · ORB) → 우측 리스크 규칙(잠금 아이콘, 코드 고정 표시, 수정 불가) + AI 판단 설정.

- 전략 카드: 켜기/끄기 토글, 파라미터는 `ParamSpec` 그대로(숫자 범위 = 슬라이더, 참·거짓 = 칩 "사용/사용 안 함", 목록 = 보라 칩), 대상 종목 칩, **배정 자본 슬라이더**(원본은 문구만 있으나 배분이 엔진에 반영되므로 입력을 둔다. 최대값 = 전체 합 1·단타 합 20% 안에서 남은 몫, 값 = 배분 % · 시장 계좌 평가액 × 배분), 백테스트 요약 블록(G1 근거의 기간·CAGR·MDD, 없으면 "검증 기록 없음"), "백테스트 보기"·"기본값 복원"(기본값과 같으면 비활성). 파라미터가 기본값과 다르면 "G1은 기본값으로 검증" 문구.
- 값은 놓는 순간 `PATCH /strategies/{name}`으로 저장하고 엔진이 5초 안에 읽는다 (ADR 0032).
- 실시간 엔진이 없는 시장(ADR 0031)의 카드는 "2단계 예정" 배지를 달고 토글을 잠근다. 배분·파라미터는 저장된다(배분 합에 들어가므로).
- ORB 카드는 `--warn-line` 테두리 + "페이퍼 전용" 배지 + 관문 G2 조건 블록(슬리피지 2¢ 포함 샤프 > 0.5, 2단계 페이퍼 기록으로 판정 — 진행률은 측정 전이라 그리지 않는다) + "실전 전환 (잠김)" 비활성 버튼.
- AI 판단 설정(`--ai-line-2` 테두리): 판단 모델 라디오(TypeSafe Jev · Laya(2단계, 잠김) · 스텁), 확신도 임계값 슬라이더 2개(바로 적용), LLM 리뷰어 체크 2개(2/2 합의, 끈 자리는 스텁), 이번 달 AI 비용(`/costs/ai`), "설정 저장". 키가 없는 모델은 고를 수 없고 "키 필요"로 표시한다. 판단 모델·리뷰어는 엔진 재시작 때 적용되며, 저장값과 엔진이 쓰는 값(`judge.active`)이 다르면 "엔진 재시작 후 적용" 배지.

### 4.4 AI 판단 로그 (`AILog.dc.html`)

상단 보정 카드 4개(Brier / ECE / 확신도 구간별 적중률 바 3개 / 게이팅 A/B MDD). 좌측 판단 표(시각·종목·판단 모델 결과·확신도·LLM 합의 배지·결과·24h 후 수익률; 선택 행은 `--ai-bg`). 우측 상세(state 원문을 모노 블록으로, 질문별 확률 6행, confidence → 구간 블록, LLM 이유 2개, 하단 "이 판단에 대해 물어보기" 입력 + 보라 버튼).
필터: 오늘/7일/4주, 시장, 전략, 결과. 표 하단 "규칙 미충족 n건은 판단 모델을 호출하지 않았습니다 (비용 0)".

### 4.5 백테스트 (`Backtest.dc.html`)

좌측 설정 300px: 전략 select, 데이터 소스(시장 실데이터 + 합성, 분봉 미국 전략은 합성만), 자산(읽기 전용), 시작/종료(월, 비우면 전체·업비트는 최근 약 1,000일), 파라미터는 전략 설정 값 사용(링크), **비용 모델 3행은 읽기 전용**(`/strategies`의 `cost_model`), 홀드아웃 체크박스는 켜진 채 잠금(불변식 #5), 상장폐지는 안내 문구("고정 종목 목록이라 해당 없음"), 파라미터 시도 카운터 주황 블록, "백테스트 실행"(진행 중이면 "실행 중… n%", WS `backtest:{id}`).

우측: 제목(전략 · 기간 · 비용 포함) + 데이터·홀드아웃·시도 횟수 문구, 실행 기록 select · 비교 추가 · "리포트 내보내기(체결 CSV)". 지표 카드 5개(CAGR·MDD·샤프·매매 횟수·최근 3년 벤치마크 대비 — 열위면 주황, 비교가 있으면 카드마다 파란 비교 값), 로그 자산 곡선(시작 = 100, 전략 보라, 벤치마크 회색 "비용 없음", 비교 파랑 점선, 홀드아웃 빗금·잠금, 열위 구간 연주황 배경), 낙폭 차트, 구간별 성과 표(전체·최근 3년·최근 1년 + 홀드아웃 "잠김", 비교 CAGR 칸), 실전 전환 전 체크리스트(✓ / ! / ○ + 문구). 원본의 "2010년 이후"·"Petit 대비" 같은 전략 고유 문구는 모든 전략에 쓸 수 있는 규칙으로 바꿨다 (ADR 0033).

### 4.6 모바일 (`Mobile.dc.html`)

세로 스택: 총 자산 카드(스파크라인 + 월 손실 게이지) → 활성 전략 리스트(토글 44×26) → 최근 AI 판단 2건 → 하단 탭 5개(홈·거래·전략·AI 판단·설정), 탭 높이 84px(세이프 에어리어 포함). 768px 미만에서 데스크톱 사이드바를 이 하단 탭으로 바꾼다.

### 4.7 포트폴리오 (원본 아트보드 없음)

원본 캔버스에 아트보드가 없어 대시보드·전략 설정과 같은 카드·토큰·문구 규칙으로 만든 화면이다. 새 보라는 쓰지 않는다(§2 규칙).

요약 카드 4개(총 자산 · 현금(총 자산 대비 %) · 보유 평가액(n종목) · 오늘 손익) → 시장별 계좌 카드 3개(업비트 · 국내주식 · 미국주식) → 자산 곡선 + 전략별 배정 대비 투입 → 보유 종목 표.

- 시장 계좌 카드: 상태 배지 "운영 중"(초록) / "2단계 예정"(회색, 실시간 엔진이 없는 시장 — ADR 0031) / "할트"(주황), 평가액 큰 숫자(미국은 달러), 현금(비중)·보유 평가액(n종목)·오늘 손익, 이번 달 손익 게이지(사이드바 월 손실 카드와 같은 색 규칙). "2단계 예정" 시장은 "저장된 계좌를 보여 줍니다" 문구, 계좌가 없는 시장은 "계좌 없음" 안내만.
- 자산 곡선: 대시보드와 같은 카드에 시장 선택(계좌가 있는 시장만) + 30일/90일/1년 탭. BTC 보유 비교선은 업비트에만 있다.
- 전략별 배정 대비 투입: 배정 = 그 시장 계좌 평가액 × 배분(ADR 0032), 투입 = 그 전략이 지금 보유한 종목의 평가액. 막대는 파랑(배분 바의 장기 조각과 같은 색), 배정보다 5% 넘게 들고 있으면 주황 막대 + "배정보다 많이 보유 중 — 배분을 줄였거나 수동 주문". 엔진이 없는 시장의 전략은 회색 막대 + "2단계 예정". 배분 0인 전략은 뺀다. 카드 오른쪽 위 "배분 바꾸기 →"는 전략 설정으로 간다.
- 보유 종목 표: 종목(시장)·전략·수량·평균단가·현재가·평가액·평가손익·계좌 비중·손절까지, 평가액 큰 순. 시장 필터는 카드 안의 선택(전체 + 계좌가 있는 시장)으로 고른다 — 상단 시장 탭은 대시보드·거래 화면에만 보이고 모바일에선 숨어서, 보이지 않는 필터가 걸리지 않게 하려는 것이다. 현재가가 없는 종목은 평균단가로 평가하고 손익은 "—"로 둔다.

상태: 로딩은 카드 골격, `/portfolio` 실패는 주황 오류 블록. 768px 미만에서는 요약 카드가 한 열, 보유 종목 표는 가로 스크롤.

## 5. 접근성·구현 규칙

- 모든 컨트롤은 실제 `<button>`·`<a>`·`<input>`+`<label>`. 토글은 `role="switch" aria-checked`. 아이콘만 있는 버튼은 `aria-label`.
- 텍스트 대비 4.5:1 이상 — `--muted`(#8A96A6)는 `--bg-2` 위에서 통과, `--muted-2`(#5C6878)는 차트 축 라벨(11px 미만 금지)에만.
- 터치 타깃 44px 이상(모바일 토글·탭).
- 실시간 갱신은 숫자만 바뀌고 레이아웃이 밀리지 않도록 폭 고정(모노스페이스 + 최소 폭).
- 색만으로 의미를 전달하지 않는다: 승인/보류는 텍스트, 상승/하락은 부호(+/−)를 함께.
- 화면의 숫자는 샘플이다. 구현 시 API 응답으로만 채우고 하드코딩하지 않는다.

## 6. 프론트 스택

Next.js 15 App Router + TypeScript, Tailwind(토큰은 위 CSS 변수로 `theme.extend`), TradingView Lightweight Charts, 상태는 WebSocket 스트림을 구독하는 zustand 스토어, 데이터 fetch는 TanStack Query. 컴포넌트 라이브러리 없이 아트보드의 마크업을 그대로 컴포넌트화한다(`components/ui/{Card, Badge, Toggle, KpiCard, ConfidenceBar, JudgmentCard, OrderPanel, ...}`).

인증·도구 배치(ADR 0018): JWT는 Next.js 라우트 핸들러가 심는 httpOnly 쿠키에만 두고, 브라우저 REST 호출은 같은 출처 프록시(`web/app/api/qp/[...path]`)가 `Authorization`을 서버 쪽에서 붙여 넘긴다. WS 토큰은 `/api/session/ws-token`에서 받아 메모리에만 둔다. Node 도구는 `web/` 안에만 있고 CI는 별도 `web` 잡으로 돌린다. 접근성(Lighthouse 90+)은 `scripts/web_demo_api.py` 데모 API를 상대로 CI에서 잰다.
