# 0003 · 리스크 규칙은 코드 상수이며 설정·화면·AI로 완화할 수 없다

상태: 승인 (2026-09-29)

## 맥락
초보 투자자가 손실 중에 한도를 풀어 버리는 것이 가장 흔한 파국이다. 설정 파일에 두면 결국 풀린다.

## 결정
`RiskRules`는 frozen dataclass 기본값이 곧 규칙이다. `Settings`에는 리스크 키를 두지 않는다(0단계에서 제거). API `PATCH /settings`는 risk 키를 거부한다. 청산 주문은 서킷브레이커·할트·비중 규칙의 예외이며 자전거래·주문 빈도 검사만 받는다. 월 서킷브레이커에는 수동 해제 기능이 없다. 완화하려면 코드 변경 + 배포가 필요하고, 그 마찰이 의도다.

## 결과
- 급한 상황에서 사람이 개입할 수 없다는 불만이 생길 수 있음 → 청산은 항상 허용되므로 "빠져나오기"는 가능.
- 규칙 값 변경은 ADR + PR로 이력이 남는다.
