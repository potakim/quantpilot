# 0004 · 1분 반응 전략에는 LLM 합의를 적용하지 않고 하루 1회 사전 심사로 대체한다

상태: 승인 (2026-09-29)

## 맥락
변동성 돌파는 목표가 도달 즉시 체결해야 한다. LLM 2모델 합의는 5~15초, 타임아웃 30초로 1분봉 전략에는 맞지 않고, 돌파 순간마다 호출하면 비용·지연 모두 문제.

## 결정
변동성 돌파는 (1) 돌파 시점에 판단 모델(≤500ms) 게이팅만 적용하고, (2) 매일 08:10 LLM 2모델이 대상 코인별 news_risk를 한 번 심사해 위험 코인을 당일 제외한다. ORB(5분)·월간 전략은 진입마다 합의를 적용한다.

## 결과
- 돌파 시점의 돌발 뉴스는 판단 모델의 news_risk(피처 빌더가 최근 뉴스를 state에 넣음)로만 걸러진다. 한계를 문서화.
