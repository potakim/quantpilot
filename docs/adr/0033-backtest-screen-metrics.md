# 0033 · 백테스트 화면: 벤치마크·구간 성과·열위 표시·비교의 정의

상태: 제안 (2026-10-04)

## 맥락
t36에서 백테스트 화면(`Backtest.dc.html`)을 만든다. 원본 화면은 API가 주지 않는 값을 보여 준다.

1. 회색 비교선("S&P 500 보유")과 지표 카드 보조줄("S&P 500 11.27%").
2. 구간별 성과 표(전체 / 2010년 이후 / 홀드아웃)와 "2010년 이후 패시브 대비 열위" 카드·배경.
3. 자산 곡선의 홀드아웃 구간. API는 잘라낸 날짜(`holdout_cutoff`)만 주고, 데이터가 끝나는 날을 주지 않는다.
4. 실행 전 비용 모델 3행. 지금은 실행한 뒤에만 `cost_model`이 나온다.
5. "비교 추가"(다른 실행 결과 겹쳐 보기). 원본의 "상장폐지 종목 포함" 체크박스는 데이터 소스가 지원하지 않는다.

원본의 숫자(1971년부터, Petit 2026 대비, 2010년 이후)는 GEM 연구에 맞춘 설명이다. 모든 전략·기간에 쓸 수 있는 규칙이 필요하다.

## 결정
1. **벤치마크 = 대표 종목을 처음에 사서 끝까지 들고 있기** (비용·세금 없음).
   - 전략마다 하나: GEM=SPY("S&P 500 보유"), 변동성 돌파=KRW-BTC("비트코인 보유"), GTAA=360750("TIGER 미국S&P500 보유"), ORB=QQQ("나스닥100 보유").
   - 전략이 이미 받은 데이터 안의 종목이라 따로 내려받지 않는다. 사용자가 종목을 바꿔 그 종목이 없으면 첫 종목을 쓴다.
   - 시작 자본은 전략과 같다. 전략 곡선의 시각에 맞춰(직전 종가) 같은 홀드아웃 컷까지 그린다.
2. **구간별 성과**는 서버가 전체 자산 곡선으로 계산한다(화면의 500점 표본으로 낙폭을 재면 작게 나온다).
   - 행: 전체 기간, 최근 3년, 최근 1년. 곡선이 그 길이보다 짧으면 그 행은 뺀다. 여기에 화면이 홀드아웃 행("잠김")을 붙인다.
   - 칸: 전략 CAGR, 벤치마크 CAGR, 전략 MDD, 초과수익(전략 CAGR − 벤치마크 CAGR, %p).
3. **열위 표시**: 최근 3년 초과수익이 0보다 작으면 다섯 번째 지표 카드를 주황으로 표시하고, 자산 곡선의 최근 3년 구간에 연주황 배경을 깐다. 원본의 "2010년 이후"를 모든 전략에 쓸 수 있는 고정 길이로 바꾼 것이다.
4. **홀드아웃**: 결과에 `data_end`(잘라내기 전 데이터의 마지막 날)를 더한다. 화면은 컷부터 `data_end`까지를 빗금·잠금으로 그린다.
   - 화면의 홀드아웃 체크박스는 켜진 채 잠근다. 해제는 실전 전환 직전 1회뿐이라(불변식 #5) 이 화면에서 풀지 않는다.
5. **실행 전 비용 모델**: `GET /strategies` 각 전략에 `cost_model`(그 시장의 `preset`)을 싣는다. 백테스터·PaperBroker가 쓰는 것과 같은 값이다(불변식 #4).
6. **파라미터**: 백테스트는 전략 설정 화면에 저장된 값으로 돌린다. 이 화면에는 파라미터 입력을 두지 않고 시도 횟수(n / 7)만 보여 준다.
7. **상장폐지 행**: 체크박스 대신 안내 문구로 둔다. 전략 종목이 고정 목록이라 생존 편향이 적용되지 않는다.
8. **비교 추가**: 끝난 다른 실행(전략 무관) 하나를 골라 겹쳐 본다. 자산 곡선에 세 번째 선(점선)을 긋고, 지표 카드에 비교 값을, 구간 표에 비교 CAGR 칸을 더한다. 새 API는 없다(`GET /backtests/{id}`를 하나 더 부른다).
9. **진행률**: WS `backtest:{id}`로 받아 실행 버튼에 보여 주고, 끝나면 결과를 다시 읽는다. WS가 끊겨도 실행 중이면 3초마다 다시 읽는다.
10. **리포트 내보내기**: 체결 전체 CSV(`/backtests/{id}/report.csv`).

## 결과
- 원본의 카드·차트·표·체크리스트를 모든 전략에 같은 규칙으로 채운다. 지어낸 숫자 없이 실행 결과와 실제 데이터만 쓴다.
- 벤치마크에는 비용이 없어서 전략보다 약간 유리한 조건이다. 전략을 좋게 보이게 하는 쪽이 아니므로 그대로 두고, 화면 범례에 "비용 없음"을 적는다.
- 백테스트 결과 JSON에 벤치마크 곡선이 더해져 파일이 커진다(곡선 하나만큼).
- 이전에 저장된 실행 결과에는 벤치마크·`data_end`가 없다. 화면은 그 칸을 "—"로 두고, 다시 실행하면 채워진다.
