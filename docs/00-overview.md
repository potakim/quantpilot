# 00 · 개요와 문서 맵

## 한 문장

초보 투자자가 검증된 퀀트 전략을 페이퍼 → 모의 → 소액 실전 순으로 안전하게 돌리게 해 주는 자동매매 플랫폼.
**코드가 계산하고(지표·신호·수량), 모델은 판단하고(국면·뉴스 리스크·확신도), 코드가 실행한다(리스크 게이트·주문).**

## 범위

| 포함 | 제외 (당분간) |
| --- | --- |
| 업비트 KRW 코인, KRX 주식·ETF(KIS), 미국 주식·ETF(KIS 실전 / Alpaca 페이퍼) | 선물·옵션·레버리지, 공매도, 해외 거래소(바이낸스) |
| 전략 4개: 변동성 돌파, GEM, GTAA, ORB | 사용자 정의 전략 코딩, 전략 마켓 |
| 판단 모델(Jev/Laya) + LLM 2모델 합의 게이팅 | LLM이 직접 매매 신호 생성, 강화학습 |
| 1인 사용자, 본인 계좌 | 다중 사용자·타인 자금 (서비스화 시 법률 검토 선행) |

## 단계와 관문

```
0 기반 구축 ──G1──▶ 1 코인 페이퍼 ──G2──▶ 2 주식 모의 ──G3──▶ 3 소액 실전 ──G4──▶ 4 확장
  (완료)      백테스트 재현    4주 페이퍼      4주 모의        8주 실전
```

| 관문 | 통과 기준 | 확인 방법 |
| --- | --- | --- |
| G1 | 비용 포함 백테스트가 **같은 기간·같은 조건**의 공개 수치 ±20% 이내(공개 기준이 없는 전략은 독립 기준 구현과 ±10%), 파라미터 시도 7회 이하 (ADR 0024) | `scripts/verify_g1.py` |
| G2 | 게이팅 ON의 MDD < OFF, 판단 모델 Brier < 0.25 | `qp report ab --weeks 4` (1단계에서 구현) |
| G3 | 주문 오류율 < 1%, 토큰·웹소켓 장애 자동 복구 | 운영 리포트 |
| G4 | 8주 서킷브레이커 미발동, 페이퍼 대비 실체결 슬리피지 차이 < 0.1%p | 운영 리포트 |

## 용어

| 용어 | 뜻 |
| --- | --- |
| Target | 전략이 봉마다 돌려주는 `(symbol, weight, price?, stop?)`. 비중은 **배정 자본** 대비 |
| 배정 자본 | 총 자본 × 전략 배분 비율. 전략은 자기 배정 자본 안에서만 비중을 정한다 |
| state | 피처 빌더가 만든 판단 입력(등급화된 지표 + 뉴스 요약, ≤400토큰) |
| 판단 모델 | Jev/Laya처럼 원자 질문에 확률·확신도를 즉시 내는 '시스템 1' 모델 |
| 게이팅 | 확신도·하드블록·LLM 합의로 진입 수량을 0 / 절반 / 전량으로 정하는 것 |
| 원장(ledger) | 모든 체결 기록. 신호·확률·확신도·체결가·수수료를 한 행에 |
| 관문(gate) | 다음 단계로 가기 위한 정량 기준. 화면의 '실전 전환' 버튼이 이 기준에 잠겨 있다 |
| 홀드아웃 | 백테스트에서 잠가 둔 최근 12개월 |

## 설계 원칙 (모든 문서에 공통)

1. **책임 분리가 안전장치다.** 계산(전략·피처)·판단(AI)·실행(리스크·브로커)을 모듈과 프로세스 경계로 나누고, AI는 실행 모듈에 접근할 수 없다.
2. **같은 코드, 다른 브로커.** 백테스트·페이퍼·실전의 차이는 `BrokerAdapter` 구현뿐이다.
3. **모든 결정은 원장에 남는다.** 확률·확신도·이유·체결가를 함께 기록해야 사후 리뷰와 보정이 가능하다.
4. **관문은 코드다.** 사람이 "이 정도면 됐지"로 넘어가지 못하게 기준을 코드와 화면에 박는다.
5. **초보자가 바꿀 수 있는 것은 적다.** 전략 ON/OFF, 파라미터 범위 내 조정, 확신도 임계값. 리스크 규칙은 못 바꾼다.
