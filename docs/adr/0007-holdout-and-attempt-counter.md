# 0007 · 홀드아웃 12개월 잠금과 파라미터 시도 카운터

상태: 승인 (2026-09-29)

## 맥락
Bailey·López de Prado: 일봉 2년 데이터에서 변형 7개 이상 시도하면 기대 최대 샤프가 과대 추정된다. 초보자는 "백테스트가 좋아질 때까지" 파라미터를 돌린다.

## 결정
백테스터는 최근 12개월을 기본 제외하고, 전략별 서로 다른 파라미터 조합 시도 수를 파일·DB에 기록해 7회 초과 시 결과에 경고를 붙인다. 홀드아웃 해제는 전략당 1회(API가 거부), 실전 전환 직전에만. 분봉 전략(ORB)은 데이터 기간이 짧아 0단계에서는 홀드아웃 0으로 실행하며, 1단계에서 기간 비율(마지막 20%) 홀드아웃으로 바꾼다.

## 결과
- 사용자가 경고를 무시할 수는 있다. 관문 G1 통과 조건에 "시도 7회 이하"를 넣어(`scripts/verify_g1.py`가 확인) 실전 버튼과 연결.
